# Scaleup CEO Playbook

Brian Halligan's 68 "Halliganisms" — from his essay
[A Startup Founder to Scaleup CEO's Journey from $0 to $25 billion](https://www.linkedin.com/pulse/startup-founder-scaleup-ceos-journey-from-0-25billion-brian-halligan-e1f4e/) —
as a progressive mind tree: **phase → theme → lesson**.

Pick where you are on the path (P1 Founding → P2 First team → P3 Pre-scale → P4 Scaleup),
open a theme, open a lesson, and tick it once it's part of how you run. Your marks, notes and
current phase are saved in your browser. A floating **Robot Brian · office hours** button links
to Brian's AI clone on Delphi.

Single self-contained file: `public/index.html`. No build step, no dependencies.

## Deploy on Render

1. Push this repo to GitHub.
2. In Render: **New → Blueprint**, pick the repo — `render.yaml` sets up a free static site
   serving `public/`.
   (Or **New → Static Site**, publish directory `public`, build command empty.)
